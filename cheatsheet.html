Cheatsheet — อ่านคืนก่อนสอบ พิมพ์ได้

กด Ctrl+P ได้เช่นกัน — ปรับ margin เป็น Default/None เลือก "Background graphics" เพื่อให้สีติดมาด้วย

ตัวเลขต้องจำ

  • FD = 3 ต่อ AD เสมอ
  • VCN CIDR IPv4 = /16 ถึง /30
  • 1 OCPU x86 = 2 vCPU · Arm A1 = 1/OCPU · Arm A2/A4 = 2 cores/OCPU
  • Realm ของ tenancy = 1 เดียว (OC1 commercial)
  • Multi-AD region = เฉพาะ region ใหญ่บางแห่ง (ส่วนใหญ่ single-AD)
  • Policy verbs: inspect → read → use → manage
  • Scoring: ดูแบนเนอร์หน้าแรก — ยืนยันกับ Oracle ก่อนสอบ

ทรัพยากร: global / regional / AD

Storage เลือกยังไง

  • Block/Boot — ดิสก์ให้ instance/DB, AD-specific, tiers + auto-tune, backup/clone/volume groups
  • Object — regional, namespace system-generated, bucket default private, tiers: Standard → Infrequent Access → Archive (Archive ต้อง restore ก่อน), lifecycle policy / versioning / replication / PAR (URL ชั่วคราวไม่ต้องมี OCI credentials)
  • File — NFS mount target, หลาย instance mount พร้อมกัน, snapshot
  • ข้อมูล PB + เน็ตไม่ไหว → Data Transfer Appliance

Security services จำให้ไว

  • Cloud Guard — detect + respond อัตโนมัติ (target/recipe/detector/responder/problem) · "ปิด public bucket ให้"
  • Security Zones — บังคับ posture ก่อนสร้าง (preventive) · "สร้าง public bucket ไม่ได้เลย"
  • Data Safe — ความปลอดภัยของ ฐานข้อมูล: sensitive data discovery, masking, audit, user assessment
  • Vault — keys (soft vs HSM, FIPS 140-2 L3) + secrets (versioning); CMK = customer-managed keys
  • WAF = L7 web (OWASP, bots) · DDoS = always-on network · Network Firewall = L3–L7 IDS/IPS + TLS inspection
  • Bastion — SSH/RDP เข้า private subnet แบบ session จำกัดเวลา + audit
  • Audit = API call ทุกตัวอัตโนมัติ · Logging = ศูนย์รวม log · Monitoring = metrics + alarms
  • at rest = AES-256 default · in transit = TLS เสมอ

IAM policy cheat sheet

Allow <subject> to <verb> <resource-type> in <location> where <cond>
  • subjects: group X · dynamic-group X · any-user · service X
  • verbs: inspect < read < use < manage (manage รวม create/delete)
  • location: tenancy · compartment Name · compartment id OCID
  • inheritance: policy บน parent → child ครบถ้วน
  • conditions ฐาน: request.region · request.networkSource.name · request.permission · tag-based (defined tags เท่านั้น)
  • instance เรียก API เอง → instance principals (dynamic group + policy ไม่ฝัง key)

Budgets vs Limits vs Quotas

เครื่องมือคือผลเมื่อเกิน
Service Limitsเพดาน tenancy/region (Oracle ตั้ง, ขอเพิ่มได้)สร้างไม่ได้
Quotasเพดาน compartment (คุณตั้ง)สร้างไม่ได้
Budgetsเพดาน เงิน (compartment/cost-tracking tag)เตือนเท่านั้น ไม่บล็อก!

ดูใช้จ่าย: Cost Analysis (กราฟ) · Cost Reports (line-item CSV) · Cloud Advisor (แนะนำ cost/security/perf/availability) · ราคาเท่ากันทุก region · Free Tier: Always Free vs trial credits

คำสัญญาณโจทย์ → คำตอบ

  • "outbound-only private subnet" → NAT Gateway
  • "ไม่ผ่าน internet, ไป Object Storage" → Service Gateway
  • "dedicated circuit แบนด์วิดท์สูง" → FastConnect · "เร็ว/สำรอง" → Site-to-Site VPN
  • "L7, path routing, TLS termination" → Load Balancer · "UDP, ultra-low latency" → NLB
  • "กัน pre-create ผิด" → Security Zones · "detect + auto-fix" → Cloud Guard
  • "instance เรียก API ไม่ฝัง key" → Instance principals
  • "ไฟล์แชร์หลายเครื่อง" → File Storage · "object URL ชั่วคราว" → PAR
  • "budget ครบ 100%" → ไม่มีอะไรถูกปิด
  • "restore ก่อนอ่าน" → Archive · "อ่านได้เลยแต่ถูกกว่า Standard" → Infrequent Access

Distributed Cloud จำชื่อ

  • Public Cloud — region สาธารณะของ Oracle
  • Dedicated Region Cloud@Customer — region เต็มของ OCI ที่ datacenter ลูกค้า
  • Oracle Alloy — partner รัน OCI ใต้แบรนด์ตัวเอง
  • Oracle AI Database@Azure / @AWS / @Google Cloud — Oracle DB รันใน cloud เจ้าอื่น
  • Sovereign / Government Cloud — ภาครัฐ/ข้อมูลอ่อนไหว
  • Roving Edge — edge พกพา offline ได้
  • Gen 2 architecture · ราคา/บริการสม่ำเสมอทุกรูปแบบ · security-first
