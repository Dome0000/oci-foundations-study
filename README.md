## ✨ จุดเด่นของโปรเจกต์ (Key Features)

### 1. 📚 คลังเนื้อหาภาษาไทย สรุปกระชับ ตรงจุดสอบ
- อธิบายด้วยภาษาไทยที่เข้าใจง่าย คงคำศัพท์เทคนิคและชื่อบริการเป็นภาษาอังกฤษตรงตามข้อสอบจริง
- มีแผนการอ่านแบบ Step-by-step 3 สัปดาห์ พร้อมระบบบันทึกความคืบหน้า (Progress Tracking) ในตัวเบราว์เซอร์

### 2. 🗂️ Flashcards คำศัพท์สำคัญ 200 ใบ (Leitner System)
- ใช้หลักการเว้นระยะทบทวน (Spaced Repetition) ด้วยกล่อง Leitner 5 ระดับ
- พลิกการ์ดด้วยปุ่มลัด `Space` / `Enter` จดจำได้รวดเร็วและแม่นยำ

### 3. 🎯 คลังแบบฝึกหัด Quiz 150 ข้อ
- คัดสรรและออกแบบตามแนวข้อสอบจริง กรองตาม Domain, Objective, ระดับความยาก (Recall / Understand / Apply)
- เฉลยพร้อมคำอธิบายแบบละเอียดทั้งข้อถูกและข้อผิด

### 4. ⏱️ ระบบจำลองสอบ (Exam Simulation)
- **โหมด 40 ข้อ 60 นาที (Passing 65%)**: สุ่มข้อสอบตามน้ำหนัก Blueprint จริง (15% / 50% / 25% / 10%)
- กราฟประวัติพัฒนาการคะแนนย้อนหลัง วิเคราะห์จุดอ่อนรายโดเมน
- **โหมด Mock Exam Simulator**: รองรับการนำเข้าชุดข้อสอบ JSON มาตรฐาน (มีชุดข้อสอบแถมในตัว 140 ข้อ)

### 5. 🔍 ระบบค้นหาอัจฉริยะ (Instant Search)
- กดคีย์ลัด `/` เพื่อค้นหาคำศัพท์ บริการ หรือแนวข้อสอบได้ทันทีทั่วทั้งเว็บไซต์

### 6. 📴 Zero Dependencies & Offline-First
- พัฒนาด้วย **Vanilla HTML, CSS และ JavaScript ล้วน**
- ไม่มี Build Step, ไม่ต้องติดตั้ง Node.js/npm และไม่ต้องต่ออินเทอร์เน็ต สามารถดับเบิลคลิกเปิดไฟล์ `index.html` แบบ `file://` ได้ทันที

## 💻 วิธีการรันในเครื่อง (Local Setup)

คุณสามารถดาวน์โหลดหรือ Clone โปรเจกต์นี้มาเปิดอ่านแบบ Offline ได้ทันที:

```bash
# โคลนโปรเจกต์ลงเครื่อง
git clone https://github.com/Dome0000/oci-foundations-study.git

# เข้าสู่โฟลเดอร์โปรเจกต์
cd oci-foundations-study
```

- **เปิดหน้าหลัก:** ดับเบิลคลิกที่ไฟล์ `index.html` หรือเปิดด้วยเว็บเบราว์เซอร์
- **เปิดคู่มือติว:** ดับเบิลคลิกที่ไฟล์ `oci-foundations-study/index.html`
- **เปิดระบบจำลองสอบ:** ดับเบิลคลิกที่ไฟล์ `mock_exam/index.html`
